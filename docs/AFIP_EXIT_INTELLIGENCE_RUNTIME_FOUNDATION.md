# AFIP Milestone W Pack W8 — Exit Intelligence Runtime Foundation

W8 converts W7 exit/reduction review signals into deterministic, auditable
exit-pressure classifications.

Outputs:
- WAIT_DATA
- MONITOR
- PARTIAL_EXIT_REVIEW
- FULL_EXIT_REVIEW

Drivers include structure break, regime reversal, momentum failure, time decay,
profit giveback, exit evidence, and independent authority failure.

This module is advisory only. It never closes, partially closes, or modifies an order.
