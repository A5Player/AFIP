# AFIP Milestone W Pack W10 — Advisory Certification & Runtime Snapshot Foundation

W10 performs read-only certification of the Milestone W advisory foundation.

It verifies:

- W2–W9 module presence
- Contract presence and JSON parseability
- Advisory/trace authority boundaries
- W9 trace contract presence
- Deterministic certification digest and snapshot ID

Results:

- CERTIFIED
- REVIEW_REQUIRED
- BLOCKED

W10 cannot make trading decisions, send orders, modify positions, close
positions, size lots, set final SL/TP, or own an MT5 session.
