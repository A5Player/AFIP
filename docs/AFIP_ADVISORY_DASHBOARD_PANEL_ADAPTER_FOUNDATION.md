# AFIP Milestone W Pack W14 — Dashboard Advisory Panel Adapter Foundation

W14 converts the W13 presentation model into a stable dashboard panel contract.

It provides:

- Stable panel ID
- Bilingual panel title
- Overall status, severity, icon, and reason
- Freshness text
- Snapshot and case identifiers
- Ordered bilingual stage rows
- Stable dictionary serialization

W14 does not mutate HTML or DOM and has no execution authority.
