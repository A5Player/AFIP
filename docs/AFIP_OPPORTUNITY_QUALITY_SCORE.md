# Opportunity Quality Score Contract

- OQS < 97: WAIT / SKIP
- 97 <= OQS < 98: entry review eligible only after every gate passes
- 98 <= OQS < 99: high-quality opportunity; every gate still required
- 99 <= OQS <= 100: elite; extended SL may be reviewed, never automatically approved

AFIP must not lower these thresholds merely to increase trade frequency.
