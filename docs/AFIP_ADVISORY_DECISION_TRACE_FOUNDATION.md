# AFIP Milestone W Pack W9 — Advisory Decision Trace & Runtime Orchestration Foundation

W9 validates and records the advisory chain:

CONTEXT → STRATEGY → PLAN → OQS → ADAPTIVE_SL → HOLDING → EXIT

Each trace contains a deterministic input digest, stable trace ID, stage status,
reason, authority state, and data-integrity state.

W9 does not execute any stage and has no order, lot, SL/TP, or MT5 authority.
