# AFIP Milestone W Pack W2 — Context Matching Engine

W2 creates a profile-independent, evidence-only context matcher. It builds deterministic market fingerprints, compares the current market with historical records, and ranks Top 100, Top 500, or Top 1000 matches.

It does not create BUY/SELL decisions, size positions, approve risk/capital, calculate executable SL/TP, import MT5, or send orders.
