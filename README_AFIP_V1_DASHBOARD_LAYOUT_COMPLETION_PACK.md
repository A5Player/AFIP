# AFIP V1 Dashboard Layout Completion Pack

Scope: presentation and read-only dashboard rendering only.

Changes:
- Operations RUNNING badge color follows runtime state only. RUNNING is green for P1-P4; red is reserved for stopped states.
- Order Evidence uses a fixed P1-P4 four-column comparison layout.
- Intelligence & Engines remains fixed at four columns in the command-center viewport.
- Unified View is removed from command-center navigation while its standalone file remains backward compatible.
- Research status and Universal Timeframe Coverage are placed side by side.
- Research ranking cards use four columns.
- Research Observability and Dashboard Audit are combined into one low-priority page near the bottom of navigation.
- Added bottom safety spacing to avoid the Windows taskbar obscuring the final rows.

No changes to trading logic, capital authority, lot sizing, SL/TP, routing, MT5 ownership, or order sending.
