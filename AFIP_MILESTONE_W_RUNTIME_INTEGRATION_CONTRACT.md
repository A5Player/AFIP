# Milestone W Runtime Integration Contract

- Do not add a launcher, supervisor, MT5 session owner or execution gateway.
- Research output is optional decision support, never an executable instruction.
- Intelligence must explicitly record whether evidence was used, unavailable, stale, quarantined or out-of-distribution.
- Missing/corrupt Research must not crash the trading runtime.
- No evidence means no research-derived confidence increase. Existing independent policy decides whether the system waits or continues in an explicit degraded state.
- Dashboard reads producer files and Runtime Authority; it must not calculate hidden trading truth.
