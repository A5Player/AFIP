# Milestone W Data Flow

Historical Data → Replay/Outcome Analysis → Research Knowledge → Current Context Matching → Strategy Evidence → Trading Plan Candidates → Intelligence Review → Confidence/Capital/Risk/Safety Gates → Existing Execution Gateway.

Open positions follow: Position State → Research Assessment → Intelligence Management Decision → Risk Approval → Existing Execution Management.

Actual outcomes return to append-only research feedback and Governance review candidates. They do not mutate Production automatically.
